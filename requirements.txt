# WAJIB DIPASANG DI PYTHON 3.11 ATAU 3.12 — BUKAN DI PYTHON SISTEM.
#

#
# Buat lingkungan terpisah, lalu arahkan backend ke sana:
#
#   py -3.11 -m venv .venv-ml
#   .venv-ml\Scripts\pip install -r requirements.txt
#   # lalu di .env:
#   PYTHON_BIN=D:\Tolongin\backend\.venv-ml\Scripts\python.exe
#
# PythonWorkerService membaca PYTHON_BIN untuk menjalankan worker biometrik.
# ============================================================================
#
# CATATAN: tensorflow sebelumnya tidak tercantum di sini sama sekali, padahal
# DeepFace membutuhkannya untuk membangun model Facenet. Akibatnya seluruh
# verifikasi wajah selalu gagal dengan "No module named 'tensorflow'", dan
# kegagalan itu tampil ke pengguna seolah wajahnya tidak cocok dengan KTP.
#
# Versi dipatok agar lingkungan pengembangan dan produksi memuat bobot model
# yang sama — bobot yang berbeda menggeser jarak embedding, yang berarti ambang
# deteksi duplikat identitas ikut bergeser.
